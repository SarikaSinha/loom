# Assignment

## Goal
Assignment: Build a Minimal Agent Framework

Using any coding agent tool or CLI, build a small agent framework from scratch. General-purpose libraries and LLM SDKs may be used, but existing agent frameworks or agent orchestration frameworks should not be used. You may use any LLM provider of your choice.

The framework should:

Use a real LLM and work end-to-end.

Be reusable enough that another developer can define and run an agent using it.

Include capabilities you consider important for a modern agent framework.
